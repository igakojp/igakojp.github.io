👑 Forum Crown — Command Reference

⚙️ Reactions

  • /reactions — Open the reaction manager dashboard
  • /condition add_role/add_user/add_tag/add_word — Conditional reaction triggers
  • /condition list/remove — Manage conditions
  • /template save/view/list/apply/delete — Reaction templates
  • /special_reaction add/remove/clear/list — Premium bonus reactions

👋 Welcome Messages

  • /welcome set — Set a welcome message for a forum
  • /welcome remove/list/preview — Manage welcome messages
  • /welcome placeholders — See all available variables

🔔 Notifications

  • /notify add_role/remove_role — Ping roles on new threads
  • /notify set_channel/remove_channel — Announce to a channel
  • /notify toggle_tags/toggle_preview/list/clear

🛡 Automod

  • /automod pin/slowmode/cooldown — Thread auto-settings
  • /automod require_tag/remove_required_tag — Tag enforcement
  • /automod archive_after/rename_prefix — Auto-management
  • /automod settings/clear — View or reset config

🏷 Special Tags

  • /special_tag set/remove/list — Assign behaviors to forum tags
  • /special_tag allow/deny/allowed_users — Manage read-only access
  • /special_tag behaviors — See all behavior types

🧵 Thread Tools

  • /thread info/close/reopen/rename — Manage threads
  • /thread tag_add/tag_remove/bump/slowmode/pin_message

📊 Statistics

  • /stats forum/top/me/server — Forum posting statistics
  • /overview — Full server settings dashboard

✉️ Post Composer

  • /post compose/list/delete_file — Compose & send messages as the bot

⚙️ Settings

  • /settings view — View all server settings
  • /settings log_channel/ignore_bots — Core settings
  • /settings blacklist_add/blacklist_remove/blacklist_view

✨ Premium & Boosts

  • /premium status — Check your tier
  • /key redeem — Redeem a Premium key
  • /boost apply/remove/credits — Use boost credits for Premium
  • /premium grant/revoke — Owner only
  • /key generate/list/revoke — Owner key management
