1. Data Collection

Forum Crown may store server IDs, user IDs, configuration settings, reaction templates, automation rules, and forum statistics.

2. Statistics

The bot tracks forum activity such as top contributors and post activity. This requires storing user IDs and activity counts.

3. Message Content

Forum Crown reads messages to process commands but does not store message content.

4. Automated Messages

The bot may send automated messages or notifications configured by server administrators.

5. Error Logs

Errors and system issues may be logged for debugging and improvement.

6. Data Storage

Data is stored in a database controlled by the developer.

7. Data Sharing

Forum Crown does not sell or share user data with third parties.

8. Data Retention

Data may remain stored even after the bot leaves a server unless a deletion request is made.

9. Data Deletion

Users may request data deletion through the support server.

10. Information Not Collected

Forum Crown does not collect IP addresses, device information, or location data.
