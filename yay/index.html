YAY! COMMUNITY TOOLS

Yay! のつながりを、
マップで見つけよう。

公開されている投稿やレターを分析して、アカウント同士のつながりを見やすく表示するツールです。

⌘
FEATURE 01

交流マップ

公開投稿の返信・メンションを集計して、誰と交流しているかをネットワークで表示します。

交流マップを開く ↗
✉
FEATURE 02

レターマップ

受け取った公開レターを送信者ごとに集計して、誰から多く届いているかを表示します。

レターマップを開く ↗
◉
FEATURE 03

通話マップ

公開タイムラインの通話投稿から、通話に参加したユーザーを集計してマップで表示します。

通話マップを開く ↗
✦
FEATURE 04

総合交流ランキング

交流・レター・通話の3つを合算して、すべての交流を通じたTop 50ユーザーを表示します。

総合ランキングを開く ↗
♛
FEATURE 05

リーダーボード

投稿にいいねするだけで参加。ミックスレベルやフォロワー数で順位が決まり、好きなユーザーから下の10人を画像で保存できます。

リーダーボードを開く ↗
↗
FEATURE 06

投稿ランキング

指定したユーザーの公開投稿から、いいね・返信・(´∀｀∩)↑age↑ が多い投稿をランキングします。

投稿ランキングを開く ↗
✎
FEATURE 07

自己紹介カード

文字・画像・お絵描きを自由に配置して、自分だけの自己紹介カードを作って画像で保存できます。

自己紹介カードを作る ↗
▣
FEATURE 08

ユーザー証

アイコン・バナー・登録日・フォロワー数などを、免許証のようなカードにまとめて画像で保存できます。

ユーザー証を作る ↗
利用について

ログイン不要。公開APIから取得できる情報のみを使用します。非公開の投稿やDMの内容は取得しません。
